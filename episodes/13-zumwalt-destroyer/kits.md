# Environments for Zumwalt Destroyer

Catalog IDs: fleet, ship, money, map, documents, timeline, blueprint, boardroom, studio, skyline.

Recurring object: a stack of shipyard order slips.

Start on the physical fleet model. Map pins identify the project's actual location. The document desk uses the source and date attached to the current claim. Put proposals and measured outcomes on separate timeline entries. Use the project model or its outline for all drawings. Boardroom and studio screens carry the decision or statement in the narration.
