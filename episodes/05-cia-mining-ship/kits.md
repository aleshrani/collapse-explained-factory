# Environments for CIA Mining Ship

Catalog IDs: recovery, ship, blueprint, map, documents, timeline, boardroom, studio, skyline.

Recurring object: a shipping manifest with an empty cargo box.

Start on the physical recovery model. Map pins identify the project's actual location. The document desk uses the source and date attached to the current claim. Put proposals and measured outcomes on separate timeline entries. Use the project model or its outline for all drawings. Boardroom and studio screens carry the decision or statement in the narration.
